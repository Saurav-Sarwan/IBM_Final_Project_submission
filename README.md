# DMart Product Catalogue Analysis

> **Pricing · Assortment · Discount · Brand Intelligence Dashboard**

A complete data analysis pipeline and interactive decision dashboard built on DMart's product catalogue dataset (5,187 SKUs across 30 categories, 87 subcategories, and 821 brands).

---

## Project Overview

This project analyses DMart's product catalogue to surface:

- **KPIs** — total products, brands, avg MRP, avg discount, anomaly counts
- **Category & Subcategory trends** — product distribution, pricing, discount depth
- **Brand performance** — top brands by SKU count and discount intensity
- **Pricing & discount patterns** — distributions, MRP vs discounted price gaps
- **Risks & Anomalies** — extreme discounts (≥70%), zero discounts, no-brand SKUs, premium mispricing
- **Opportunities** — assortment gaps, under-promoted categories, premium segment gaps
- **Management recommendations** — 10 prioritised actions across three time horizons

All insights are surfaced through an interactive, browser-based 7-tab decision dashboard.

## Quick Start

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the analysis

```bash
python main.py
```

This will:
- Load and clean `DMart.csv`
- Run all 8 analytical phases
- Write 9 JSON output files to `outputs/`
- Print progress to the terminal

Expected output:
```
=======================================================
  DMart Product Catalogue Analysis - Backend Engine
=======================================================

[1/8] Loading and cleaning data ...
      5,187 valid product records loaded.
[2/8] Computing KPIs ...
  [saved] outputs\kpis.json
...
[DONE] Analysis complete. All outputs written to /outputs/
       Launch frontend/dashboard.html in a browser to view results.
```

### 3. Open the dashboard

Open `frontend/dashboard.html` in any modern browser (Chrome, Firefox, Edge).

> **Note:** The dashboard reads `../outputs/*.json` using relative paths. Keep the file structure intact. If you get a "Data not found" message, ensure you ran `python main.py` first.

## Backend Analysis Phases

The backend ([`backend/analysis.py`](backend/analysis.py)) runs 8 sequential phases:

1. **Data Loading & Cleaning** — reads CSV, coerces types, fixes reversed prices, drops null/zero rows
2. **Feature Engineering** — computes `DiscountAmount`, `DiscountPct`, `PriceRange` buckets, boolean anomaly flags
3. **KPI Computation** — 12 headline metrics
4. **Category Analysis** — group by Category: count, brand count, avg MRP, avg/max discount, high-discount count
5. **Brand Analysis** — top 30 brands by SKU count and discount intensity; single-product brand detection
6. **Discount & Price Distributions** — 9-bucket discount histogram and 6-bucket price range breakdown
7. **Anomaly Detection** — flags extreme discounts (≥70%), zero discounts, no-brand products, premium+high-discount
8. **Opportunity Identification** — single-brand subcategories, low-discount categories, over-promoted subcategories, premium segment gaps
